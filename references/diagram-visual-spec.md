# 工作图表视觉规范 · Geist 绿白

> 适用：飞书画板（beautiful-feishu-whiteboard / lark-cli）里产出的**工作型图表**——全景图 / 骨架图 / 路线图 / 机制图等。源自「眼见为实」DESIGN.md（Geist/Vercel）。薛张明 2026-06-22 确认采纳。
> **一句话原则：让位于内容——用层级、留白、细边框和一个绿色组织信息，不用重色/阴影/装饰。**

## 一、调色板（只用这些 token，禁裸配色）

**中性灰阶（承担 90%）**
- 页底 `#FAFBFB`｜卡面 `#FFFFFF`｜卡片边框 `#E1E3E4`（2px）
- 标题字 `#0A0C0C`｜正文/卡内字 `#1A1E1F`｜辅助字 `#6B7173`｜连线/箭头 `#4A5052`

**品牌绿（唯一强调色，单色）**
- 主绿 `#10A37F`（标题条、数据条、中枢节点、强调）｜浅绿底 `#E7F6F0`｜绿字 `#0B7355`
- 规则：**一张图只让绿色做"主路径/已确认/最重要"**；绿色出现 = 这里重要。

**四档状态语义色（浅底 + 同色描边 + 深字）**

| 状态 | 底 | 描边/点 | 用途 |
|---|---|---|---|
| 已有方案/已确认 | `#E7F6F0` | `#10A37F` | 收口的 |
| 已共识 | `#E9F1FC` | `#3B7DE0` | 达成一致 |
| 待共创 | `#F0ECF9` | `#7E57C2` | 与业务共创 |
| 待拍板/待办 | `#FCF2E1` | `#E8A23D` | 需决策（用琥珀，不用红） |
| 真异常（少用） | `#FBE9E7` | `#D9534F` | 仅"错/风险"才用红 |

文字在浅语义底上要强调时用对应深字：绿 `#0B7355` / 蓝 `#2C5FB0` / 紫 `#7E57C2` / 琥珀 `#8A5B12`。

**分类色（当颜色表"类别"而非"状态"，如分支/分场）**：绿 `#10A37F` / 蓝 `#3B7DE0` / 琥珀 `#E8A23D` / 紫 `#7E57C2` / 中性深 `#0A0C0C`（中枢或首尾用）。

## 二、视觉规则
1. **边框优先于阴影**：静态卡片**不用阴影**，用 2px `#E1E3E4` 边框分隔；深度靠留白和层级。
2. **标题条用主绿** `#10A37F` + 白字；卡面白、页底近白。
3. **浅底深字、深底白字**；浅语义底上强调用对应深色字。
4. **直角或统一小圆角**（rx 0–8，同图一致）；间距走 4px 栅格、留白充足。
5. **一图一主强调**：绿色只给最重要的一个点争注意力，其余中性。

## 三、飞书画板的硬限制（必须遵守）
- 只用原生形状（rect/circle/line/text），**不设 `font-family`**。
- 箭头一律 `marker-end` 原生连接器，**禁手画三角/polygon**。
- **禁** gradient / filter / opacity / 模糊；本规范默认**不用阴影**。
- **绝不要在画板 SVG 文字里放 emoji**（⭐🚀🎯⚠️🅿️ 等 pictographic）——whiteboard-cli 渲染遇 emoji 会在该处**静默中断、后续元素全不画**（PNG 只出半张却报 error:""、--check warnings:0，极难发现）。用色块/底色/①②③ 圈号替代。
- 导出 PNG 的**文字颜色不可靠**（白字常变黑）——核验颜色用 `--output_as raw` 或看线上，别信导出图。
- **货币/生僻符号会渲染成豆腐块**：`₦`（奈拉 U+20A6）在 whiteboard-cli 与飞书线上字体里都缺字形，画板上一律写 `NGN`。
  只影响画板，**飞书文档正文里 `₦` 正常**，两边不必统一。同类风险符号：`₵ ₱ ₸`。
- ⚠️ **`<text>` 里禁裸等号 `=`**——会让飞书服务端**画板转图服务永久失败**：写入返回 `ok=true`、`+query --output_as raw` 查得到全部节点且坐标正常，
  但 `--output_as image` 永远返回同一张 43,778 字节的「加载中」占位图，**文档里那块画板就是白的**。等多久都不会好。
  用「含 / 即 / 等于」改写，或换 `≈ ≥ ≠`（这三个实测正常）。2026-08-24 单变量实测：同一份 SVG 只把一处 `1 个周期 = 2 个还款期` 改成 `含`，
  缩略图立刻从 43 KB 占位变 327 KB 真图。
  **和 emoji 那条是同一类静默失败，但更阴**：emoji 至少本地 PNG 只出半张，等号在本地 PNG、`--check`、`check_fonts.py` 里全部正常。
  **唯一的发现方式是推完拉一次线上图看字节数**——这就是第 4 步线上验收不能跳的理由。
  排查纪律：先拉一张**别人的老画板**做对照，能出真图就说明是自己内容的问题、不是平台故障，再二分定位新引入的字符。

## 四、范式选型

**四类主范式（默认从这四个里挑）**
- **全景图**：分层铺（地基 → 支柱 → 运营 → 终局），每块按四档状态上色，底部放绿色硬数据条。
- **骨架图**：中枢（绿）+ 主干（分类色）的浅层导图，**只到模块层、不画细节**，做"讨论锚点"。
- **路线图**：横向阶段/分场卡片流，首尾用中性深、中段用分类色，产出用语义 tag。
- **机制图**：左右或上下对照 + `marker` 箭头，突出"一个机制怎么运转"。

**这四类套不上时，去扩展库挑**（详细画法/上限/反模式见 本仓库 `references/patterns.md`）：

| 内容形态 | 范式 |
|---|---|
| 单据/对象的状态流转（转移单、管控单、公示期） | 状态机 |
| 3 个以上角色互相交接的流程 | 泳道 |
| 怎么切期（1 期 / 2 期 / 以后）+ 本期切线 | 故事地图 |
| 一个结果的多个原因（归因分析） | 鱼骨 |
| 两个维度上的定位 / 优先级 | 象限 |
| 谁依赖谁，且存在多父或环 | 依赖图 |
| 排期、并行轨道、里程碑 | 甘特 |
| 转化流失、分层人数分布 | 漏斗 / 金字塔 |
| 事件在时间上的先后（间距必须诚实） | 时间轴 |
| 一个角色的体验 + **每阶段的情绪** | 用户旅程 |
| 有数据要量化（对比/占比/趋势/流量） | 定量图表（见 skill 的 quant-charts.md） |
| 一个总量从上期到本期怎么变（各因素贡献） | 瀑布图 |
| 系统/角色之间谁先调谁、等待点在哪 | 时序图 |
| 首尾能接成一个自我强化的环 | 闭环飞轮（接不成环就用机制图） |
| 这期系统改了哪几块（新增/改造/下线） | 架构前后对比 |
| 表与表怎么关联、外键在哪 | ER 图 |
| 两个维度的格子里找异常和走势 | 热力图 |
| 只有两个时点，看谁升谁降 | 斜率图 |
| 目标 vs 实际，看差距 | 哑铃图 |

> **先问语义再选版式**：先答"读者要看懂的是什么"——是状态、是交接、是归因、是取舍、还是情绪？
> 答完再挑图。跳过这一步直接按"内容长什么样"选，最常见的错是把归因画成流程、把分期画成路线图。

## 五、构图预算（硬上限，画之前先定）

1. **强调预算 = 恰好 2 个元素，动手前点名是哪两个。** 不是"绿色少用"，是"这张图只有 A 和 B 是绿的"。
   给到第 3 个，信号归零。每种范式的这 2 个该给谁，patterns.md 里逐条写了。
2. **主节点 ≤ 9 个，密度目标 4/10。** 超了大概率是两张图。超预算时**聚合成一个带计数的节点**
   （"其余 6 项"），**不要静默删**——聚合了要说一句。
3. **删除测试**：每个节点/每条线/每个标签都要能过"删了会丢什么信息"。两个总是一起出现的节点 = 一个节点；
   关系已能从位置看出来的线 = 删掉；颜色或形状已经表达的标签 = 删掉。

## 六、连线规则（推送前跑 `check_geometry.py`）
- 连接器走直角（水平/竖直），斜线只留给飞轮、鱼骨、斜率图。
- 端点离节点角 ≥ 8px，从边的中段出入；线不穿不相干的卡片、不贴边框跑，两条线不共线重叠。
- 线上的标签先垫一块背景色实心圆角矩形再写字；图例统一放结论条上方一行。

## 七、产出流程
作 SVG（逻辑宽 ~1500–1700）→ `whiteboard-cli -i x.svg -o x.png -f svg` 渲染 → 看图修（溢出/对齐/边距/半张图）→ 推送 `whiteboard-cli --to openapi | lark-cli whiteboard +update`。
换肤脚本见本仓库 `scripts/recolor_geist.py`（状态/结构型，含阴影删除+语义映射）与 `scripts/recolor_geist_cat.py`（分类型）——把 linen 配色的画板批量转成 Geist。
