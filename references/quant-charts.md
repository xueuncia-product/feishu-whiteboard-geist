# 定量图表 · Geist 绿白（飞书画板可编辑）

工作型图表除了结构范式（全景/骨架/路线/机制），常需要**把数据量化**：对比、占比、趋势、流量。
这一档用 `scripts/quant_charts.py` 生成 5 类经典图表，全部 Geist 绿白配色、原生节点、可在画板二次编辑。

## 什么时候用哪张

| 业务问题 | 选这张 | 函数 |
|---|---|---|
| 规模+质量同框（营收 vs 利润率等双指标） | 分组柱+趋势折线（双 Y 轴） | `bar_line()` |
| 只有一个核心 KPI / 进度要讲 | 环形仪表盘 | `gauge()` |
| 多维选型/竞品对比（谁强在哪） | 雷达图 | `radar()` |
| 转化 / 漏斗 / 流量分流 | 桑基流向图 | `sankey()` |
| 增长构成 / 增量来源（多序列叠加） | 堆叠面积图 | `stacked_area()` |

## 用法（3 步，接主流程）

```python
import sys; sys.path.insert(0, "<此 skill>/scripts")
from quant_charts import bar_line, gauge, radar, sankey, stacked_area
open("chart.svg","w",encoding="utf-8").write(
    gauge("季度目标完成度", 78, "领先进度 · Top 10%", sub="单一 KPI 一眼读懂"))
```
然后照 [SKILL.md](../SKILL.md) 第 2–3 步：`whiteboard-cli` 渲染看图 → `--to openapi | lark-cli whiteboard +update` 推成可编辑画板。
每个函数的完整入参见文件顶部 docstring 与 `__main__` 里的调用示例（`python3 quant_charts.py` 会生成 5 张 `_demo_*.svg` 供参照）。

## 每张的算法要点（照搬即对）

- **bar_line**：双 Y 轴共用绘图区——左轴驱动柱高、右轴驱动折线；柱顶数值 + 折线空心点 + 双侧刻度。折线 % 标签放数据点**右上**（末点左上），避开柱顶数值。`line_unit` 定折线单位（`%` / `×` …）。**已知限制：折线 series 必须 ≥ 0**（右轴按 `max×1.25` 映射，不含负区）——同比/环比下降类要传**绝对值降幅**并把 `line_name` 写成"降幅%"，别直接传负数（会把线甩出画布）。柱可传 1–2 组做前后对比。
- **gauge**：极坐标弧——270° 量程从 135° 起顺时针，按 pct 映射弧长，用 `<path>` 的 `A`（椭圆弧）命令绘制；`%` 单位放大字右侧、别压中心数字。
- **radar**：N 维顶点按 `-90°+360°·i/N` 三角函数算坐标；两序列各一个 `<polygon>`，**用实色浅底（green_lt/blue_lt），不要 opacity**（画板会忽略透明度）；右侧记分卡逐维标"谁领先"。
- **sankey**：流量守恒——每条流带 = 上下两条共享中点 x 的三次贝塞尔 `<path>`，按左节点分类色**实色填充**；节点用 `<rect>`，左标签在右、右标签在左。
- **stacked_area**：先算每层累计边界，面积 = 上边 L→R 折线 + 下边 R→L 折线闭合成 `<path>`；顶端轮廓缀空心圆点标全局大盘。

## 图表质量原则（Tufte，画之前先自省）

好看 ≠ 好图。落数据前按这几条自查，宁减勿加：

- **提高 data-ink 比**：每一滴墨都该编码数据。去掉不承载信息的装饰——重网格、外边框、背景块、3D、阴影一律砍。生成器里网格已用最浅灰 `#eef0f0` 且只 4~5 条，别加深加密。
- **直接标注 > 图例**：能把标签写在数据旁就别让读者去比图例颜色。生成器已做（柱顶数值、折线点 %、桑基/面积层名）；系列 ≤2 且已直接标注时，图例可省。
- **range-frame / 轴做减法**：轴只画到数据范围，刻度别铺满；单位放轴端一次即可。
- **small multiples**：多组别对比时，宁可并排几张小图（同轴同尺度），也别把 5+ 序列堆进一张——桑基/堆叠面积是例外（它们本就为"合起来看"而生）。
- **诚实**：柱状轴从 0 起（`bar_line` 已如此）；双轴、截断轴、面积图要清楚标注，别用视觉夸大变化。
- **一图一结论**：标题/副标题直接写出这张图要让人看到什么（"既增收又增利"），别只写"季度数据"。

## 画板硬规则（实测，务必遵守）

- **渐变一律失效**：`linearGradient` 会被拍平成纯色 → 别靠渐变做体积感；Geist 本就纯扁平，无损。
- **透明度被忽略**：`opacity` / `fill-opacity` 全渲染为不透明 → 雷达/桑基叠加区用**实色浅底**表达，别用半透明。
- **曲线能做原生 `<path>` 但略"糊"、难二次编辑**：仅桑基流带、面积填充、仪表弧这类**必须**曲线处才用 path；柱/点/轴/网格一律 rect/circle/line。
- 不设 `font-family`；SVG 文字**禁 emoji**（会静默断图）；配色只用 `GEIST` token。
- 出图后 `whiteboard-cli --check`：柱+折线的"折线压柱""桑基流带交叠"是**有意叠加**，看图判断即可，不必清零 nodeOverlap。
